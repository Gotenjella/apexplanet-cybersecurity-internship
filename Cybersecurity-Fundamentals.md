# Cybersecurity Fundamentals

## 1. CIA Triad

The CIA Triad represents three fundamental objectives of cybersecurity:
Confidentiality, Integrity and Availability.

### Confidentiality

Confidentiality ensures that information is accessible only to authorized
users, systems or processes.

Examples:

- Authentication
- Access control
- Encryption
- Password protection

### Integrity

Integrity ensures that information remains accurate and is not modified,
deleted or tampered with without authorization.

Examples:

- File integrity monitoring
- Hash verification
- Digital signatures
- Access controls

### Availability

Availability ensures that systems, applications and information remain
accessible to authorized users when required.

Examples:

- Backups
- Redundancy
- System monitoring
- Disaster recovery

# 2. Common Cyber Threats

## Phishing

Phishing is a social engineering technique in which an attacker attempts
to trick a user into revealing sensitive information or performing a
malicious action.

## Malware

Malware is malicious software designed to disrupt systems, steal information,
damage data or gain unauthorized access.

Examples include:

- Viruses
- Worms
- Trojans
- Spyware
- Ransomware

## DDoS

Distributed Denial-of-Service attacks attempt to make a service unavailable
by overwhelming it with traffic or requests from multiple systems.

## SQL Injection

SQL Injection is a web application vulnerability in which malicious input
is used to manipulate SQL queries.

Potential impact includes:

- Unauthorized database access
- Data disclosure
- Data modification
- Authentication bypass

Testing should only be performed against authorized applications or
intentionally vulnerable laboratory systems.

## Brute Force

A brute-force attack attempts to discover credentials by systematically
trying many possible passwords or combinations.

Defenses include:

- Strong passwords
- Multi-factor authentication
- Rate limiting
- Account lockout
- Monitoring

## Ransomware

Ransomware is malware that can encrypt or otherwise deny access to data
and demand payment from victims.

Defenses include:

- Offline backups
- Endpoint protection
- Patch management
- Network segmentation
- Security monitoring

# 3. Attack Vectors

## Social Engineering

Social engineering manipulates people into revealing information or
performing actions that benefit an attacker.

## Wireless Attacks

Wireless attacks target wireless communication or devices.

Examples include:

- Rogue access points
- Weak authentication attacks
- Wireless traffic interception
- Misconfigured wireless networks

Wireless security should be tested only on networks for which permission
has been obtained.

## Insider Threats

Insider threats originate from individuals who have legitimate access to
an organization's systems or information.

They may be:

- Malicious insiders
- Compromised users
- Negligent users

---

# 4. Security Principles

Important cybersecurity practices include:

- Least privilege
- Strong authentication
- Secure configuration
- Regular patching
- Network segmentation
- Logging and monitoring
- Backups
- Security awareness
