# Task 1 – Foundations & Environment Setup

## Objective

The objective of Task 1 is to build foundational knowledge in cybersecurity,
networking and cryptography and establish a controlled cybersecurity
laboratory environment.

## Topics Covered

### 1. Cybersecurity Basics

- CIA Triad
- Confidentiality
- Integrity
- Availability
- Phishing
- Malware
- DDoS
- SQL Injection
- Brute Force
- Ransomware
- Social Engineering
- Wireless Attacks
- Insider Threats

### 2. Lab Environment

- VirtualBox / VMware
- Kali Linux
- Metasploitable2 / DVWA
- Host-Only network configuration

### 3. Linux Fundamentals

- File system navigation
- File and directory permissions
- Package management
- Networking commands

### 4. Networking

- OSI Model
- TCP/IP
- DNS
- HTTP/HTTPS
- IP addressing
- Subnetting
- NAT

### 5. Cryptography

- Symmetric encryption
- Asymmetric encryption
- Hashing
- MD5
- SHA-256
- Digital certificates
- SSL/TLS
- OpenSSL

### 6. Security Tools

- Wireshark
- Nmap
- Burp Suite
- Netcat

## Deliverables

- Lab Setup Report
- Cybersecurity fundamentals notes
- Networking notes
- Cryptography notes
- Linux command cheat sheet
- Security tools overview
- Lab screenshots
- Task 1 walkthrough video

## Authorization and Scope

All practical activities are performed only against intentionally configured
laboratory systems and authorized targets.

No unauthorized systems, third-party infrastructure, or public targets are
tested as part of this internship task.
