# Networking Notes

## 1. OSI Model

The OSI model contains seven layers.

| Layer | Name | Example |
|---|---|---|
| 7 | Application | HTTP, DNS |
| 6 | Presentation | Encryption, encoding |
| 5 | Session | Session management |
| 4 | Transport | TCP, UDP |
| 3 | Network | IP |
| 2 | Data Link | Ethernet, MAC |
| 1 | Physical | Cables, signals |

## 2. TCP/IP Model

The TCP/IP model commonly consists of:

- Application
- Transport
- Internet
- Network Access

## 3. TCP

TCP is a connection-oriented transport protocol that provides reliable
delivery of data.

## 4. UDP

UDP is a connectionless transport protocol with lower overhead than TCP.
